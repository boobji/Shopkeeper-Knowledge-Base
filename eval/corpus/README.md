本目录存放检索评测用的原始文档（PDF）。**语料文件不入库**，需要时按下面的命令重新拉取。

## 来源

- 数据集：[RealAppliance](https://github.com/gaoyz1235/RealAppliance) —— 100 本真实家电产品手册（多语言）
- 中文版共 30 本，覆盖 11 类家电；其中 **28 本**可直接下载（约 156 MB），
  另 2 本为超大扫描版（013 = 32 MB、017 = 59 MB），受 CDN 20 MB 单文件上限限制，默认跳过。

## 获取

```bash
python scripts/fetch_eval_corpus.py            # 下载全部 30 本
python scripts/fetch_eval_corpus.py --limit 5  # 试跑：只下前 5 本
```

脚本特性：断点续传、双通路自动回退（jsDelivr → GitHub Contents API）、并发下载、
按上游 **Git blob SHA1 逐文件校验完整性**、失败清单输出。
下载完成后在本目录生成 `manifest.csv`，记录编号 / 品类 / 文件名 / 大小 / 校验来源。

```bash
python scripts/fetch_eval_corpus.py --include-huge   # 连 013/017 一起拉（走 git 稀疏克隆，很慢）
```

> 013（32 MB）、017（59 MB）超过 jsDelivr 的 20 MB 单文件上限，GitHub Contents API
> 对其返回 500，只剩 git 稀疏克隆一条路；实测拉取十几分钟仍未完成，且两本都是图多的
> 扫描版、解析成本高，因此默认跳过——28 本已足够支撑评测。
